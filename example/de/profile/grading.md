# Bewertung

## Notenraster

**A, passt direkt.** Die Kernanforderung ist durch ein konkretes Projekt oder eine Station im Profil gedeckt, Niveau und Ort stimmen. Höchstens eine kleinere Lücke.

**B, lohnt einen Blick.** Die Richtung stimmt, aber es gibt eine erkennbare Hürde (eine Technologie, ein Erfahrungswunsch an der oberen Grenze, eine fremde Branche).

**C, Grenzfall.** Mehrere Lücken oder die Stelle passt nur über eine Nebenschiene.

Im Zweifel eine Stufe tiefer bewerten.

## Vorlage

(wird von der Stellensuche nicht gebraucht, nur das Notenraster oben)
